# Dise-o-de-un-prototipo-de-software-de-planificaci-n-familiar-para-la-unidad-amigable-
Prototipo de software de planificación familiar para la Unidad Amigable de la Universidad de Cundinamarca, seccional Girardot. Ofrece módulos educativos sobre anticoncepción y prevención de ITS, orientación personalizada sobre métodos anticonceptivos y agenda de citas. Hecho en Python con Flet y SQLite.
